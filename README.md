# Lihan Zuo Academic Homepage

This branch contains the published static build for `zuo-lihan.github.io`.

- Published branch: `master`
- Development branch: `develop`
- Legacy site backup: `old`

GitHub Pages reads this branch from the repository root. The live page is served from `index.html`, with supporting files in `assets/`, `sections/`, `docs/`, and `img/`.

For future edits, switch to `develop`, update the source files under `preview/`, run the local preview/build commands documented there, then promote the confirmed static output back to `master`.
